# Симуляция адаптивной аттестации

Python 3.10 или новее. Внешние зависимости не требуются.

```bash
python3 simulation.py
python3 simulation.py --response-model 3pl
python3 simulation.py --employees 1000 --repeats 20 --seed 42 --near 0.5
```

По умолчанию скрипт моделирует 1 000 сотрудников в одном повторе. Каждый запуск создаёт отдельный каталог `run-*` внутри `results/`. Параметр `--output` задаёт другой родительский каталог. При одинаковых параметрах результаты воспроизводятся. При нескольких повторах для каждого генерируются новые сотрудники и ответы, а банк и блоки MST общие для всего запуска. Сводка объединяет сотрудников всех повторов.

## Устройство эксперимента

В банке 90 синтетических заданий. На каждую из трёх тем приходится по 10 лёгких, средних и сложных заданий. Различающая способность `a` равномерна от 0,8 до 1,8. Трудность `b` равномерна в пределах ±0,5 от центра своей ступени (−1,5, 0 или 1,5). Для каждого задания отдельно задаётся параметр псевдоугадывания `c`, равномерный от 0,10 до 0,25.

Истинные уровни θ генерируются из N(0, 1). До начала тестов для каждой пары «сотрудник — задание» независимо разыгрывается ответ. Вероятность успеха по 2PL равна `L = 1 / (1 + exp(-a * (θ - b)))`, а по 3PL равна `c + (1 - c) * L`. При совпадении задания у двух методов ответ совпадает. Методы видят ответы только на выбранные ими задания. [Описание модели 3PL](https://www.stata.com/manuals18/irt.pdf)

| Метод | Правило выбора |
|---|---|
| По правилам | Начинает со средней ступени. После каждого ответа сдвигается на ступень вверх или вниз в пределах трёх ступеней. Из доступных заданий нужной темы и ступени выбирает одно равновероятно. |
| MST | Общий блок содержит по два средних задания на тему. Следующий блок содержит по два задания на тему нужной ступени. Маршрут лёгкий при 0–2 верных ответах, средний при 3–4, сложный при 5–6. Блоки формируются до начала тестов, задания общего блока исключаются из второго этапа. |
| CAT 2PL | Стартует с априорной оценки 0. Выбирает незаданное задание нужной темы с максимальной информацией Фишера `a²p(1 − p)` при текущей EAP-оценке и пересчитывает её после ответа по 2PL. |
| CAT 3PL | Использует ту же процедуру с EAP по 3PL и информацией Фишера `a²L²(1 − p) / p`, где `p = c + (1 − c)L`. |

Во всех тестах 12 уникальных заданий, по 4 на тему. В обоих CAT и тесте по правилам темы чередуются в одном и том же порядке. Параметр `--response-model` задаёт модель для генерации общей матрицы ответов и итогового EAP у всех четырёх методов. По умолчанию используется 2PL. В режиме `3pl` ответы и итоговый EAP учитывают псевдоугадывание. В каждом режиме сравниваются правила выбора заданий при общей модели итоговой оценки.

Итоговая оценка θ̂ для всех методов равна апостериорному среднему EAP с априорным N(0, 1). Интегралы аппроксимируются на сетке от −8 до 8 с шагом 0,1.

## Результаты

- `report.md` — таблица для доклада. В ней RMSE и средняя ошибка θ̂ − θ по всей выборке и по группам θ < −1, −1 ≤ θ < 1, θ ≥ 1 и |θ| ≤ 0,5. Ширина последней группы задаётся через `--near`.
- `metrics.csv` — те же показатели с исходной точностью и знаменателями. Ошибочный зачёт делится на число сотрудников с θ < 0, ошибочный незачёт — на число сотрудников с θ ≥ 0. Зачёт выставляется при θ̂ ≥ 0. При нулевом знаменателе ячейка остаётся пустой.
- `tests.csv` — одна строка на сотрудника, метод и повтор. Коды двух вариантов CAT — `cat` для CAT 2PL и `cat_3pl` для CAT 3PL. Поле `item_ids` содержит идентификаторы заданий по порядку, поле `answers` — строку ответов из 0 и 1 в том же порядке.
- `bank.csv` — параметры заданий, включая `c`, и принадлежность к блокам MST.

Сравнение характеризует четыре правила выбора при заданном банке, модели ответов и распределении подготовленности.
